02 · 공유

시스템 흐름도 (데이터 이동)

생산 데이터 → Central Server(Whitelist / Life Cycle) → 고객사 환경 → ESL 단말
데이터 통합 및 수명주기 관리

구간별 연계

  • MES(생산 DB) → 중계 서버(본사) → Central Server : 생산·포장·출하 데이터 전달
  • Central Server : 출하–박스–MAC 관계(Ship Master → Ship Data → Packing_box → Packing_box_inner_mac)와 Whitelist / Life Cycle 관리
  • Box Scan Mobile App → Central Server : 고객 인도 전 Box / MAC 스캔 및 Customer Code(Store Code) 등록 — App 접속 ↗
  • Central ↔ 고객사 Environment Server : Whitelist 및 최초 Activation 정보 Daily 교환
  • Environment Server → Gateway : 허용 MAC 적용 → ESL 단말 Activation

Notes

  • Store Code는 선택 항목
  • RMA 서버는 기존 사용 중인 서버와 Tool은 유지하고, RMA 정보만 Central Server에서 받아오는 방향 등을 검토 중
  • 실제 시스템 테이블 및 연계 방식은 내부 설계에 따라 변경될 수 있음
03 · 논의 안건

Whitelist 등록을 위한 Box Scan 정책

Box Scan Mobile App 접속 ↗
출처: Whitelist_Process.xlsx › Whitelist Tab (17~23행)
Case스캔 시점장소 및 수행 주체처리할 내용논의 필요 사항회의 결정사항 (메모)
1. PO에 찍힌 그대로 고객 인도출하 시
(기존과 동일)		기존 공장 출하 담당
1.고객에게 인도될 Box에 PO에 찍힌 최종 고객 Customer Code 할당
1.PO 발주 고객, 실제 출하처(법인·총판·SI 파트너 등), Whitelist 최종고객을 각각 구분하여 관리하고, 단계별 식별 코드의 통합 또는 연동 방안 논의
2.코드 누락·오류 발생 시 출하 전 정정 절차
2. 법인·창고를 거쳐 고객 인도고객 인도 직전각 영업 담당자가 이행 여부 관리
1.제공된 App으로 Outer / Inner Box 스캔
2.최종 고객의 Customer Code 지정
3.Store 지정은 Option (고객이 요구하거나 Shop-in-shop일 경우)
1.장소와 관계없이 고객 인도 전 등록
2.박스 단위 스캔을 기본으로하고, 법인은 담당자 지정과 등록 이행을 관리
3.고객 인도 전 배정 변경이나 오등록이 확인되면, 해당 등록 담당자가 Customer Code와 Store 정보(선택)를 수정하고 변경 이력 관리
3. 유통사·리셀러를 거쳐 고객 인도최종 고객 확정 후
고객 인도 직전		외부 파트너사 담당 법인이 이행 관리
1.파트너용 App으로 Box Scan 및 최종 고객의 Customer Code 등록
1.외부 채널에도 고객 인도 직전 Whitelist 등록
2.법인이 유통사·총판 등에 정책을 안내하고 실제 이행되도록 관리
4. 법인·본사에서 수령 후 낱개로 분할·배분고객 인도 직전각 영업 담당자가 이행 여부 관리
1.Inner Box를 개봉해 인도할 개별 Label의 MAC 스캔 → Customer Code 지정
2.Store 지정은 Option (고객이 요구하거나 Shop-in-shop일 경우)
1.낱개 인도분도 개별 스캔 후 Whitelist 등록 완료 후 출하
2.Central Server에 저장된 원천 데이터의 Inner Box별 MAC의 최종 고객 정보 할당과 Whitelist 등록 여부(Y/N) 조회 가능한 인터페이스 제공
3.낱개를 고객에게 인도하는 Box는 Central Server에서 관리하지 않음
5. 설치 현장에서 누락된 Label 식별설치 중 Activation이 되지 않는 경우설치 현장 AE / SI
1.개별 MAC 스캔 후 Customer Code 지정
2.Store 지정은 Option (고객이 요구하거나 Shop-in-shop일 경우)
1.현장 설치 AE·SI에 등록 권한 부여
2.누락 제품은 현장에서 보완하고, 정상 등록분은 재스캔하지 않음
